## Claude Code

The `plone-doc-style` plugin is mandatory in this repository.
If the skill `plone-doc-style` is missing in your session, stop before any work under `docs/` and have it installed:

```
/plugin marketplace add plone/plone-doc-style-skill
/plugin install plone-doc-style@plone-doc-style-skill
```

In the VS Code extension, use **Manage Plugins** instead of the slash commands.
Restart the session afterward, then invoke the skill for every page you plan, write, edit, or review.
