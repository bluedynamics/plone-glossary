# Reference

The reference describes the package as facts that you look up while you work.

- {doc}`settings` lists the settings, the `data-glossary` attribute, the optional block views, and the names of the old add-on.
- {doc}`components` describes the public API, the components, the markup, the CSS classes, and the custom properties.
- {doc}`matching-rules` lists the rules by which the package finds terms in a text.
- {doc}`known-limits` lists the known limits of the package and the supported size of a glossary.
- {doc}`compatibility` lists the supported versions of Volto, React, Node.js, and the backend, and the tested browsers.
