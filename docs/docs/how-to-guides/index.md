# How-to guides

The how-to guides show you the steps to one goal in your own Volto project.
They assume that you know how to work with Volto and Plone.

- {doc}`install` installs the package in an existing Volto project.
- {doc}`limit-tooltips-to-routes` shows tooltips on selected routes only.
- {doc}`add-tooltips-to-a-block` shows tooltips in the text of your own block.
- {doc}`tooltips-in-cards` keeps tooltips accessible in a card that links to another page.
- {doc}`migrate-from-volto-slate-glossary` moves a project from `@rohberg/volto-slate-glossary` to this package.
- {doc}`test-accessibility-by-hand` checks the tooltips with a keyboard, screen readers, voice control, and a phone.
